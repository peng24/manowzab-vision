# Manowzab Vision - AI Dataset Generation Pipeline

คู่มือการใช้งานระบบสร้างชุดข้อมูล (Dataset) อัตโนมัติสำหรับโมเดล Vision (เช่น YOLOv8) 
ระบบมีการเชื่อมต่อและใช้โมเดล **OWLv2** (Zero-Shot Object Detection จาก Google) ในการดึงกรอบวัตถุและป้ายราคาโดยที่คุณไม่ต้องมานั่งตีกรอบเอง (Manual Annotation) และทำการแปลงเป็นรูปแบบไฟล์ข้อความสำหรับเอาไปฝึก YOLO ได้ในทันที

---

## 🛠️ โครงสร้างโฟลเดอร์ที่เกี่ยวข้อง

- `scripts/extract_frames.py`: สคริปต์แยกภาพ (Frames) จากวิดีโอ MP4
- `scripts/auto_annotate.py`: สคริปต์หลักสำหรับหาพิกัดและสร้างไฟล์ Label
- `data/raw_frames/`: โฟลเดอร์สำหรับเก็บภาพต้นฉบับทั้งหมดที่รอการตรวจจับ
- `data/train/images/`: โฟลเดอร์เก็บภาพที่เจอวัตถุ (ผ่านการคัดมาแล้ว) และพร้อมใช้งาน
- `data/train/labels/`: โฟลเดอร์เก็บไฟล์ `.txt` ที่เป็นกล่องแบบ YOLO

---

## 🚀 ขั้นตอนการใช้งาน

### ขั้นตอนที่ 1: แยกเฟรมภาพออกจากไฟล์วิดีโอ (Extract Frames)
หากคุณบันทึกคลิปวิดีโอรายการขายของไว้ ให้นำมาสกัดเป็นภาพนิ่งทีละชิ้นส่วนก่อน

**คำสั่งที่ใช้งาน:**
```bash
python scripts/extract_frames.py --video "29-3-69.mp4" --output "data/raw_frames" --fps 1
```

**คำอธิบายพารามิเตอร์:**
- `--video`: ระบุชื่อไฟล์วิดีโอของคุณ เช่น `29-3-69.mp4`
- `--output`: แฟ้มเป้าหมายที่ต้องการให้บันทึกภาพนิ่ง (ปกติชี้ไปที่ `data/raw_frames`)
- `--fps`: ความถี่ที่ต้องการสกัดภาพ (เช่น `1` คือดึงออกมา 1 เฟรม ต่อ 1 วินาที เพื่อไม่ให้ได้รูปที่ซ้ำซ้อนเยอะเกินไป)

---

### ขั้นตอนที่ 2: ทำ Auto Annotation ด้วย OWLv2
ระบบจะนำภาพทั้งหมดจาก `data/raw_frames` มาวิ่งผ่าน AI เพื่อค้นหาสิ่งที่เราต้องการหา เช่น "ป้ายราคา" หรือ "ฉลากสินค้า"

**คำสั่งที่ใช้งานพื้นฐาน:**
```bash
python scripts/auto_annotate.py
```

**คำสั่งแบบละเอียด (ปรับแต่งการค้นหาได้):**
```bash
python scripts/auto_annotate.py --prompts "price tag, product label, text label" --conf 0.15 --limit 1000 --sample 2
```

**คำอธิบายพารามิเตอร์ของ `auto_annotate.py`:**
- `--prompts` : ใช้สำหรับระบุสิ่งที่เราอยากให้ตรวจหาขั้นต้น (Prompt) คั่นแต่ละคำด้วยเครื่องหมายคอมม่า (`,`) ตัวอย่างปกติจะเป็น `"price tag, product label"`
- `--conf` : ระดับความแม่นยำขั้นต่ำ (Confidence Threshold) ที่จะให้ระบบมองว่ารูปนั้นๆ คือสิ่งที่เราให้หา (ค่าเริ่มต้น `0.2`)
  - *แนะนำ: ถ้าเห็นว่า AI ตีกรอบไม่ค่อยเจอเลย ให้ลองลดลงมาเป็น `0.1` หรือ `0.15`*
- `--limit` : จำกัดว่าต้องการดึงรูปมาสุ่มทดลองตรวจจับแค่กี่รูป เช่น `--limit 100` เอาไว้เพื่อเทสความแม่นยำ (ค่า `0` หมายถึงให้ตรวจทั้งหมดใน `raw_frames`)
- `--sample` : ดึงรูปมาทำงานแบบกระโดดข้าม (ข้ามทุกๆ N รูป) เช่น `--sample 5` เพื่อลดปัญหารูปมุมซ้ำกันหลายๆ ใบเกินไป

### ขั้นตอนที่ 3: ตรวจสอบความถูกต้อง
หลังจากที่สคริปต์รันเสร็จแล้ว:
1. ระบบจะดึงรูปที่เจอเป้าหมาย ไปเรียงไว้ให้ที่ `data/train/images/`
2. ระบบจะวางพิกัด YOLO ไว้ชื่อเดียวกับรูป ที่ `data/train/labels/`

*(รูปภาพที่ไม่เจอวัตถุ สคริปต์จะข้ามและทิ้งไว้ที่ `data/raw_frames` ตามเดิม สามารถย้ายออกไปเก็บยังแฟ้มอื่นอย่าง `data/archive/` ได้เพื่อนำมาใช้เป็น Negative Images)*

---

## 💡 คำแนะนำหรือ Best Practices 

- ถ้ารันจบรอบแล้วได้รูปเข้า `data/train/` เป็นที่พึงพอใจแล้ว **ควรสร้างโฟลเดอร์ เช่น `data/processed_frames/` แล้วย้ายภาพต้นฉบับจาก `raw_frames` ที่ใช้แล้วไปเก็บไว้เป็น Archive** 
- ไม่ควรลบภาพดิบนั้นทิ้งเผื่อเวลาเราเปลี่ยนใจอยากรัน Auto-Annotate ด้วยความแม่นยำที่เข้มงวดมากกว่าเดิม หรือเปลี่ยน Prompt ข้อความใหม่
- ไฟล์ในโฟลเดอร์ `data/train/` (ทั้ง `images/` และ `labels/`) คุณสามารถนำไปบีบอัด (.zip) หรือโยนเข้าโมเดลเตรียม Train ยอดนิยมในตระกูล YOLOv8 ได้ทันที
